任何编程语言的学习，都从**搭建环境、写出第一个程序、成功运行**开始。

本章将带你从零搭建 C++ 开发环境，编写并运行经典的 Hello, World!，并理解程序从代码到可执行文件的完整过程。

## 2.1 本章学习目标

- 学会在 Windows 下搭建 C++ 开发环境
- 理解编译器、IDE、编辑器的区别
- 写出第一个可正确编译、运行的 C++ 程序
- 理解 `#include`、`main` 函数、标准输出等基础结构
- 能够独立排查最常见的编译、运行错误

## 2.2 开发环境选择与说明

### 2.2.1 什么是编译器

C++ 是**编译型语言**，需要编译器将源代码翻译成机器可执行的二进制文件。

常用编译器：
- GCC / G++（开源、跨平台）
- Clang（苹果 / LLVM 生态）
- MSVC（微软 Visual Studio 内置）

### 2.2.2 什么是 IDE

IDE = 编辑器 + 编译器 + 调试器 + 项目管理

适合新手的 C++ IDE：
- Visual Studio（Windows 最友好、功能最强）
- CLion（跨平台、智能提示强，付费）
- Code::Blocks、Dev-C++（轻量但较老旧）

### 2.2.3 编辑器 + 编译器（轻量方案）

- VS Code + MinGW（GCC for Windows）
- 灵活、体积小、适合习惯手动配置的学习者

本章重点介绍两种最主流、最适合新手的方案：
1. Visual Studio（一键式，推荐零基础）
2. VS Code + MinGW（轻量跨平台）

## 2.3 Windows 环境搭建：Visual Studio

### 2.3.1 下载与安装

1. 进入官网：https://visualstudio.microsoft.com/
2. 下载 **Community 社区版**（免费）
3. 运行安装器，在工作负荷中勾选：
    - **使用 C++ 的桌面开发**
4. 等待安装完成（约 3–10 分钟）

### 2.3.2 创建第一个项目

1. 打开 Visual Studio
2. 创建新项目 → 选择 **空项目 (Empty Project)**
3. 设置项目名称与路径
4. 右键 **源文件 → 添加 → 新建项**
5. 选择 **C++ 文件 (.cpp)**，命名如 `main.cpp`

至此环境准备完成。

## 2.4 跨平台轻量方案：VS Code + 编译器

### 2.4.1 安装 VS Code

官网下载安装：https://code.visualstudio.com/

### 2.4.2 安装 MinGW（GCC/G++）

1. 下载 MinGW-w64
2. 配置系统环境变量 `Path`，加入 `mingw64/bin`
3. 打开命令行，输入以下命令验证：

```bash
g++ --version
```

显示版本号即成功。

### 2.4.3 安装 VS Code 插件

- C/C++（微软官方）
- Code Runner（可选，一键运行）
- Chinese (中文界面，可选)

### 2.4.4 新建并保存文件

新建文件 → 保存为 `main.cpp`（后缀必须为 `.cpp`）

## 2.5 第一个 C++ 程序：Hello, World!

在编辑区输入以下代码：

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, C++ New Classic!" << endl;
    return 0;
}
```

**运行方式**
- Visual Studio：按 `F5` 或点击【本地 Windows 调试器】
- VS Code + Code Runner：右键 → 运行代码
- 命令行手动编译：

    ```bash
    g++ main.cpp -o main
    main.exe
    ```

    运行成功后，控制台输出：

    ```plaintext
    Hello, C++ New Classic!
    ```

## 2.6 代码逐行解析

① `#include <iostream>`
- `#include` 是预处理指令
- 作用：引入输入输出库 `iostream`
- 没有它，`cout`、`cin` 无法使用

② `using namespace std;`
- std` 是 C++ 标准库的命名空间
- `cout`、`endl` 都属于 `std`
- 新手阶段可以加上，简化代码书写

③ `int main()`
- 程序入口函数，所有 C++ 程序从这里开始执行
- `int` 表示函数返回一个整数类型结果
- 一个程序有且仅有一个 main 函数

④ `cout << ... << endl;`
- `cout`：标准输出（控制台打印）
- `<<`：输出运算符
- `endl`：换行并刷新缓冲区

⑤ `return 0`;
- 返回给操作系统一个状态码
- `return 0` 表示程序正常结束
- 非 0 通常表示异常退出

## 2.7 编译与运行原理简介

C++ 程序执行分为三步：
1. 编辑：写代码，保存为 `xxx.cpp`
2. 编译：编译器将 `.cpp` → 目标文件 `.obj`
3. 链接：链接器将目标文件 + 标准库 → 可执行文件 `.exe`
4. 运行：系统加载执行，输出结果

简单理解：

```mermaid

    A[源代码] --> B[编译] --> C[链接] --> D[可执行程序]
```

## 2.8 常见问题与错误排查

### 2.8.1 报错：cout 未定义
- 忘记写 `#include <iostream>`
- 忘记写 `using namespace std`;

可改为：
```cpp
std::cout << "..." << std::endl;
```

### 2.8.2 中文乱码
- VS Code / 控制台编码不统一
- 解决方案：文件保存为 **UTF-8** 或 **GBK**

### 2.8.3 命令行 g++ 不是可运行命令
- MinGW 未加入系统环境变量 Path
- 重启终端后重试

### 2.8.4 程序一闪而过
- 程序执行完直接退出
- 解决方法：

```cpp
system("pause");  // Windows
// 或
cin.get();
```

## 2.9 本章总结
- C++ 是编译型语言，需要编译器 + 编辑器 / IDE
- Visual Studio 最适合零基础新手
- 程序从 `main()` 开始执行
- `#include <iostream>` 提供输入输出能力
- `cout` 用于在控制台打印内容
- 代码必须严格区分大小写、注意分号和括号配对

掌握环境搭建，才算真正踏入 C++ 开发的大门。

## 2.10 课后练习

1. 搭建好 C++ 环境并成功运行 `Hello, World!`
2. 修改字符串，输出自己的名字，例如：
    ```plaintext
    Hello, my name is Tom.
    ```
3. 尝试打印多行内容，使用多次 `cout` 或多个 `endl`
4. 不使用 `using namespace std;`，改写程序并成功运行
